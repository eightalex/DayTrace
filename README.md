# DayTrace

Приватний локальний трекер активності для macOS.

## Що вже працює

- автоматично фіксує активну програму й заголовок вікна;
- для Claude/ChatGPT/Codex намагається брати назву активного завдання, для Telegram — назву активного чату, для браузерів — назву активної вкладки;
- Codex і сесії Claude Code відносить до розробки, а звичайні чати Claude та ChatGPT — до AI-інструментів;
- об’єднує послідовні виміри у часові сесії;
- визначає перерву після 5 хвилин без клавіатури або миші;
- показує хронологію та час за категоріями;
- показує горизонтальний графік від першої до останньої активної події, зберігаючи паузи між задачами;
- позначає перерви діагональною штриховкою, а крайні межі графіка — спільним заокругленням;
- при наведенні виділяє вибрану подію й показує над графіком її назву, застосунок, категорію, час і тривалість;
- дозволяє змінити категорію застосунку безпосередньо в рядку хронології;
- має менеджер категорій з іконками застосунків і drag-and-drop між категоріями;
- зберігає ручні призначення категорій та застосовує їх до наступних сесій застосунку;
- працює в menu bar;
- має власну іконку в Dock і Finder;
- дозволяє приховати іконку з Dock, не зупиняючи запис;
- зберігає дані тільки локально у `~/Library/Application Support/DayTrace`;
- не робить скриншотів і нічого не передає мережею.

## Збірка

```bash
chmod +x build-app.sh
./build-app.sh
open /Applications/DayTrace.app
```

Зібраний застосунок встановлюється тільки в `/Applications/DayTrace.app`; у папці проєкту копія `.app` не залишається.

Скрипт використовує native build system, оскільки поточний Swift 6.4 Command Line Tools має проблему з розбором plist у стандартному `swiftbuild`.

Перевірка класифікації активностей:

```bash
chmod +x test.sh
./test.sh
```

Під час першого запуску натисніть **«Надати доступ»** і дозвольте DayTrace у:

`System Settings → Privacy & Security → Accessibility`

Без цього дозволу назви деяких вікон будуть порожні, але назви програм продовжать записуватися.

Локальна ad-hoc збірка має стабільний designated requirement за bundle ID, тому Accessibility-дозвіл зберігається між наступними збірками. Після переходу зі старого підпису один раз вимкніть і повторно ввімкніть DayTrace у списку Accessibility.

DayTrace читає лише назви активних вікон, завдань, чатів і вкладок через macOS Accessibility. Текст повідомлень, сторінок і відповідей не зберігається.

## Приватність

Заголовок вікна може містити назву документа, вкладки браузера або чату. Запис можна призупинити з головного вікна чи menu bar. Сирі дані доступні кнопкою **«Показати дані у Finder»**.
